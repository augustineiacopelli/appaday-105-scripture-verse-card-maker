# AppADay 105: Scripture Verse Card Maker

Part of the [AppADay](https://augustineiacopelli.github.io/appaday/) project: one functional web app, every day.

## What it does

Turns any Scripture reference and verse text into a shareable image card. Choose from four visual templates (solid, gradient, dotted pattern, framed), toggle dark or light mode, and export as a PNG or copy the finished card straight to the clipboard.

## Features

- Four card templates: solid, gradient, subtle dot pattern, and a framed border style
- Dark mode / light mode toggle applied across every template
- Live canvas preview that updates as you type
- Auto-sizing verse text that scales down to fit longer passages
- Download as PNG (1080x1080, share-ready)
- One-tap copy to clipboard, with a text fallback if image clipboard isn't supported by the browser
- Fully responsive from a 375px phone screen up through desktop

## Stack

Vanilla HTML, CSS, and JavaScript. Canvas API for rendering. Google Fonts (Playfair Display, EB Garamond, Inter) for typography. No frameworks, no build step, no dependencies.
